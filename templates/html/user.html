Dynamic DNS API
YOUR API KEY

Update an A record in your zone by sending an HTTP POST request:

POST {{website_url}}/update/{HOSTNAME}
POST {{website_url}}/update/{HOSTNAME}?ip={NEW_IP}

HOSTNAME must be the relative name as it appears in your zone file (e.g. home or @). If not present, it will be created.
NEW_IP is optional. The external IP from the request will be used if omitted.

Authorization

Provide your API key in one of two ways:

  • As X-API-Key in the HTTP header:
    curl -X POST -H 'X-API-Key: {{user_token}}' '{{website_url}}/update/{HOSTNAME}'
  • As api_key in the URL query string:
    curl -X POST '{{website_url}}/update/{HOSTNAME}?api_key={{user_token}}'
